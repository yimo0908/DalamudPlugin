# Dalamud 插件仓库

这是由 yimo 维护的 Dalamud 插件仓库，为最终幻想14提供各种实用插件。


## 如何安装

在卫月插件市场中添加本仓库后，即可搜索并安装下方列出的所有插件。

1. 在游戏内输入 `/xlplugins` 打开卫月插件市场。
2. 点击左下角的 **设置**（齿轮图标），切换到 **实验功能** 选项卡。
3. 在「自定义插件仓库」中点击 **+** 按钮，粘贴以下仓库链接：

   ```
   https://raw.githubusercontent.com/yimo0908/DalamudPlugin/main/repo.json
   ```

4. 点击 **保存**，卫月会自动拉取仓库中的插件信息。
5. 返回插件市场，在搜索框中输入插件名称即可找到并安装。

> 仓库链接指向的 `repo.json` 包含了本仓库内所有插件的元数据，添加后无需重复操作，后续插件更新会自动同步。
